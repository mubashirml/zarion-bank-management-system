# 🏦 ZaRion Bank Management System

A console-based Bank Management System developed with Python for practicing real-world programming concepts and basic banking operations.

## 📌 Project Overview

ZaRion Bank Management System is a Python-based console application designed to simulate basic banking operations through an interactive terminal interface.

The project combines multiple Python programming concepts into one practical application.

## ✨ Features

- Create a new bank account
- Deposit money
- Withdraw money
- View account details
- Update account information
- JSON-based data persistence
- Interactive console-based menu
- User input handling

## 🛠️ Technologies Used

- Python
- JSON
- File Handling
- Object-Oriented Programming
- Functions
- Conditional Statements
- Loops

## 🧠 Python Concepts Practiced

- Variables

- Conditional Statements

- Object-Oriented Programming
- File Handling
- JSON Data Handling
- Data Persistence
- User Input and Output
